
## Assignment

### Dependencies

Java JDK

JDBC

### Environment Setup

**Recommended OS:**

Windows 11

**Recommended IDE:**

VSCode

**Recommended VSCode extensions:**

Java by Oracle Corporation, oracle.com

Gradle for Java by Microsoft, microsoft.com

### Run project

(in parking_lot_management_system directory, containing gradlew)

**Run project:**
`./gradlew run`

**Build executable jar:**
`./gradlew shadowJar`

**Run executable jar:**
`java --enable-native-access=ALL-UNNAMED -jar app/build/libs/parking_lot_management_system.jar`
